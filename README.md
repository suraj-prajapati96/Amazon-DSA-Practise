# 📚 Amazon Interview Preparation

A curated collection of **Data Structures and Algorithms (DSA)** problems organized by difficulty and implemented in both **C++** and **Java**. This repository is dedicated to interview preparation for **Amazon** and other top product-based companies such as Google, Microsoft, Meta, Apple, Adobe, Uber, and Atlassian.

The goal of this repository is to improve problem-solving skills, strengthen algorithmic thinking, and prepare for coding interviews through consistent practice.

---

- 📂 Organized by difficulty (Easy, Medium, Hard)
- 💻 Solutions in **C++** and **Java**
- 📖 Clean and well-structured code
